# 요청 기록

제품 방향에 대한 요청과 그때 정한 것을 날짜순으로 쌓는다.
새 요청으로 화면·기능·규칙이 바뀌면 맨 아래에 한 항목을 추가한다(무엇을 요청했나 → 무엇을 정했나 → 어디에 반영했나).
편집기 안에서 쌓이는 수정 기록(`data/history.json`)과는 다르다. 그쪽은 편집 취향, 이쪽은 제품 결정이다.
